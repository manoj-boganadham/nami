# Nami — UI Requirements (v3)

This document describes the design specifications for integrating the **Mode of Payment** picker into the dashboard interface.

---

## 1. Visual Indicators (Pills & Badges)

Each transaction row in the history list will display a **Mode of Payment** badge next to the category selector.

### 1.1 Styles and Emojis

| Mode | Emoji | Background | Text Color |
|---|---|---|---|
| UPI | 📱 | `bg-sky-500/10` | `text-sky-600 dark:text-sky-400` |
| Card | 💳 | `bg-purple-500/10` | `text-purple-600 dark:text-purple-400` |
| Cash | 💵 | `bg-emerald-500/10` | `text-emerald-600 dark:text-emerald-400` |
| Net Banking | 🌐 | `bg-indigo-500/10` | `text-indigo-600 dark:text-indigo-400` |
| Unspecified (None) | ❓ | `bg-stone-500/10` (dashed) | `text-stone-400` |

---

## 2. Interactive Selector Design

To resolve overflow clipping issues once and for all:
- We will use a beautifully styled **native HTML `<select>` dropdown** for the Mode of Payment, styled identically to the category picker.
- The select menu will show the selected mode with its emoji and text.
- If it is unspecified, it shows a muted grey outline with text `Select Mode`.
- Hovering over the selector highlights the box with a subtle light background.
- Changing options will trigger a backend update instantly and reload states without flash.
- Standard payment modes: `UPI`, `Card`, `Cash`, `Net Banking`.
- A blank option `Unspecified` will be available to clear the selection.
