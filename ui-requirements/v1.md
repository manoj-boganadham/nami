
# Nami — Dashboard & UI Requirements (v1)

> *"Every berry counts."*  
> Inspired by Nami from One Piece — the Straw Hat crew's navigator and treasurer.

---


## 1. Design Philosophy

Nami is a personal finance tracker for a single user, focused on privacy, speed, and accuracy. The dashboard is inspired by Nami's role as treasurer and navigator: every spend is logged, categorized, and visualized with clarity. The UI is designed for fast manual categorization, clear analytics, and a nautical/treasure-inspired aesthetic. No AI-based auto-categorization is performed; all categorization is manual for accuracy.

## 5. Component Specs

### 5.1 Header
- Logo: custom SVG emblem (stylized Mikan/orange blossom with tangerine staff motif)
- App name: **NAMI** in Cinzel, gold
- Subtitle: "Berry Tracker · Personal Finance" in muted uppercase
- Date filters: pill-shaped chips — Today / 7 days / 30 days / Custom
- Active chip: filled gold (`#e89220`) with dark text
- **Theme toggle:** Sun/moon icon button on the far right of the header. Clicking switches between light (default) and dark theme. Preference stored in `localStorage` and applied on page load via a `data-theme` attribute on `<html>`.

### 5.2 Stat Cards (top row)
Four cards, each with:
- Colored top border (2px) indicating type: gold / teal / red / blue
- Muted uppercase label
- Large Cinzel number
- Delta line (green = improvement, red = increase in spend)

Labels use Nami-flavored language:
- "Today's Haul" instead of "Today's Spend"
- "Weekly Total"
- "Flagged Spends"
- "Transactions"

### 5.3 Category Panel
- Each category: emoji icon in colored pill + name + amount + mini progress bar
- Bar fill color matches the category's accent color
- Categories: Food 🍛, Transport 🚕, Shopping 🛍️, Utilities ⚡, Health 💊, Entertainment 🎮, Other 📦


### 5.4 Transaction List
- Each row: colored dot (category color) + raw SMS snippet or description + category tag (if assigned) + amount
- Uncategorized transactions: visually highlighted (muted row + tag), show inline category picker on click/tap
- Flagged items (above ₹2,000): show a red `⚑ Flag` badge inline
- Max 5–6 rows visible; scroll for more

### 5.5 7-Day Bar Chart
- Simple bar chart, gold bars
- Today's bar: full opacity gold
- Past days: 50% opacity
- Day labels below bars
- Today's label: gold + medium weight


### 5.6 Nami Illustration Panel
- SVG illustration of Nami character (simplified, tasteful)
- Name + "Berry Navigator" subtitle
- Dynamic status badge at bottom:
  - Green: "All funds accounted for!"
  - Red: "X flagged spends today"
  - Amber: "Above average spending day"

## 8. Theme Toggle

- **Default:** Light theme (warm parchment)
- **Toggle:** Sun ☀️ / Moon 🌙 icon button in the top-right corner of the header
- **Persistence:** Store preference in `localStorage` key `nami-theme` (`"light"` or `"dark"`)
- **Implementation:** Apply `data-theme="dark"` on `<html>` for dark mode; all colors defined as CSS variables scoped to `[data-theme="dark"]`
- **Transition:** Smooth `transition: background 0.25s, color 0.25s` on the root element — no jarring flash
- **SSR / first load:** Read `localStorage` before first paint to avoid flash of wrong theme

```css
:root {
  --bg-primary: #fdfaf5;
  --bg-surface: #f5f0e8;
  --text-primary: #1a1810;
  /* ...all light tokens */
}

[data-theme="dark"] {
  --bg-primary: #0a0e1a;
  --bg-surface: #0f1525;
  --text-primary: #f0ead6;
  /* ...all dark tokens */
}
```

## 10. Tech Stack Recommendation

| Layer | Choice | Why |
|---|---|---|
| Frontend | React + Tailwind | Fast iteration, component-based |
| Charts | Recharts or Chart.js | Lightweight, fits the bar chart needs |
| Fonts | Google Fonts CDN | Cinzel + DM Sans |
| Icons | Lucide React or Tabler Icons | Clean, consistent |
| API calls | React Query | Simple fetch + cache for report data |

## 11. Pages / Routes

| Route | Page |
|---|---|
| `/` | Dashboard (default: today) |
| `/?range=7d` | 7-day view |
| `/?range=30d` | 30-day view |
| `/?from=&to=` | Custom range |
| `/dashboard` | Main dashboard (API: `/api/transactions`, `/api/stats`) |
| `/api/transactions` | List transactions (supports `?date=`, `?from=&to=`) |
| `/api/transactions/:id` | Update transaction category (PATCH) |
| `/api/stats` | Aggregated stats for a date range |
