# Nami — UI Requirements (v2)

This document describes the design system and layout details for the Log Book tab in **Nami v2**.

---

## 1. Tab Selector (Header Integration)

- **Placement:** Placed on the left of the date range picker in the header, or directly below the main title.
- **Design:** A pill-shaped segmented controller similar to the date range picker.
  - Tabs: **The Chart Room** (Analytics) and **The Log Book** (Raw Logs).
  - Selected tab: filled gold background (`#e89220`) with dark text in light mode, and gold text with subtle outline in dark mode.
  - Hover states: light gray background expansion (`#ede8dc` / `#1a2040`).

---

## 2. The Log Book View Layout

When the user selects **The Log Book**, the main content area (below stats cards) swaps from the charts and transaction lists to the raw messages interface:

```
┌────────────────────────────────────────────────────────┐
│  FILTERS: [Search input...]    [Status select: All ▾]  │
├────────────────────────────────────────────────────────┤
│  MESSAGES LIST (Scrollable or Paginated)               │
│                                                        │
│  ID   Message Text         Received At   Status    Action│
│  ──   ────────────         ───────────   ──────    ──────│
│  12   "Spent ₹150..."      Today 12:30   [Parsed]  [ ]   │
│  11   "Verify code: 5.."   Today 10:15   [Failed]  [Rep] │
│  10   "Monthly balanc.."   Yest 23:00    [Pending] [Rep] │
└────────────────────────────────────────────────────────┘
```

### 2.1 Filters Bar
- **Search bar:** An input box with a search icon (magnifying glass) and text "Search logs...".
- **Status Filter:** A custom dropdown or standard select element showing options:
  - All Logs
  - Pending Logs (Gold/Amber border)
  - Parsed Logs (Teal/Green border)
  - Failed Logs (Red border)

### 2.2 Raw Message Table/Grid
- Row heights are compact, with dividers (`border-border-default/30`).
- Alternating row backgrounds: Warm White (`#fdfaf5`) and Parchment (`#f5f0e8`) in light mode; Navy Deep (`#0a0e1a`) and Navy Mid (`#0f1525`) in dark mode.
- Hover state: Row gains a subtle highlighted border and background fill.

### 2.3 Status Badges

| Status | Text | Background | Border | Text Color |
|---|---|---|---|---|
| Parsed (Processed & Succesful) | `Parsed` | `#1a9e82/10` | `#1a9e82/30` | `#1a9e82` |
| Pending (Not Processed) | `Pending` | `#e89220/10` | `#e89220/30` | `#e89220` |
| Failed (Processed & Failed) | `Failed` | `#cc3333/10` | `#cc3333/30` | `#cc3333` |

### 2.4 Action Buttons
- **Reprocess Button:** A small, flat pill button displaying `Reprocess` or an icon (e.g. refresh arrow).
  - Background: Gold orange outline or faint fill.
  - Hover: Becomes fully filled gold with text color shift.
  - Disabled / Loading state: Displays a spinner, opacity is lowered, click is blocked.
